# Menu Maker by Qwenta

Projet réalisé dans le cadre de ma formation **Testeur logiciel / QA chez OpenClassrooms**.

## 🎯 Objectif du projet

Préparer et planifier le développement de **Menu Maker**, une application permettant aux restaurateurs de créer, personnaliser et publier leurs menus en ligne.

L'objectif de ce projet était de transformer les besoins fonctionnels en une solution technique structurée et de préparer l'organisation du développement.

## 🛠️ Travail réalisé

- Analyse des besoins fonctionnels
- Rédaction des spécifications techniques
- Définition de l'architecture de l'application
- Choix des technologies
- Découpage en user stories et tâches techniques
- Priorisation des fonctionnalités
- Estimation de la complexité en story points
- Organisation et planification avec un Kanban
- Mise en place d'une veille technologique

## 💻 Architecture et technologies étudiées

La solution technique proposée repose notamment sur :

- **React** pour le front-end
- **Express / Node.js** pour le back-end
- **PostgreSQL** pour la base de données
- **Auth0** pour l'authentification
- Une **API REST** pour les échanges entre le front-end et le back-end

Les choix techniques prennent également en compte la sécurité, l'accessibilité, la maintenabilité et l'évolutivité de l'application.

## 📋 Organisation du projet

Le projet a été découpé et organisé dans un **Kanban** comprenant notamment :

- les user stories ;
- les tâches techniques ;
- les priorités ;
- les dépendances ;
- les critères de succès ;
- les estimations en story points.

## 📚 Veille technologique

Une veille technologique a également été mise en place afin d'identifier et de suivre les évolutions pouvant influencer les choix techniques du projet.
